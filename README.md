# Hi, I'm Narendra — Data Engineer in Dublin, Ireland

I build batch and incremental pipelines on Azure Databricks, Delta Lake and Azure Data Factory that turn messy operational and financial data into reliable, tested, analysis-ready tables. 5+ years across data engineering and data analytics; MSc Data Analytics, National College of Ireland (2025).

**Focus areas:** lakehouse pipelines (Bronze/Silver/Gold), SCD Type 2 modelling, data quality and reconciliation, incremental loads and performance tuning.

**Currently learning:** Snowflake, dbt, Kafka and RAG / LLM engineering.
